📐 派生指标公式速查

指标公式说明
人均月成本avg_cost_per_person = cost / person_count区域级=该区总成本÷该区人月数；全局=总成本÷总人月数。全部2位小数(W2)
人均月工时avg_hours_per_person = hours / person_count区域级=该区总工时÷该区人月数；全局=总工时÷总人月数。1位小数后+h
环比变化率mom(a,b) = (a-b)/b × 100%a=最新月值，b=前月值。正绿色+前缀，负红色-前缀。b≤0 显示"—"
成本占比pct = 各区cost / 全部cost合计 × 100%环形图标注: 区域名 + pct% + ¥万 + 人数
万元换算W(n)=(n/10000).toFixed(0)   W2(n)=(n/10000).toFixed(2)总额用W(整数)，人均用W2(2位)。USD区域→FMTU=$万，CNY区域→FMTW=¥万
去重人数unique_persons = Set(all names)跨所有月份去重计数。person_months = 各月人数相加（不去重跨月）

🪙 USD vs CNY 区域差异

项目USD 区域 (MS/WE/GL/Ground)CNY 区域 (TX/NE)
成本数据源r.cost → r.orig_cost (原币USD)r.cost (本币CNY)
金额格式FMTU = $+W(n)+万FMTW = ¥+W(n)+万
人均格式W2 → toFixed(2) (USD万元)W2 → toFixed(2) (CNY万元)
标签文字CNY→USD, 万h→h, 本币→原币保持 CNY / 本币
